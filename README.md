# GBPBot 用户手册

GBPBot（机器人昵称：Q群管家Pro）是一个 QQ 群机器人。在群聊或私聊中发送指令即可与它交互。

## 可用指令

指令以 `/` 开头，直接发送即可，无需 @ 机器人：

| 指令 | 说明 |
| --- | --- |
| `/help` | 回复本手册的地址 |
| `/react <表情>` | 给这条消息贴上指定表情，支持 QQ 自带表情与 emoji，如 `/react 😄`；若该消息引用了其它消息，则改为给被引用的消息贴表情 |
| `/rf [large\|l] [emoji\|e]` | 随机发送一个表情：默认为 QQ 小黄脸，加 `large`（`l`）改为随机发送大黄脸（超级表情），加 `emoji`（`e`）改为随机发送 emoji，两个参数互斥 |
| `/exempt @成员 <理由>` | 把指定成员加入免验证名单，之后不再检查该成员的群昵称（仅群主、管理员或超级用户可用），如 `/exempt @张三 老师` |
| `/duel @成员 [倍率]` | 向指定群成员发起猜拳决斗；倍率为不超过 100 的正整数（默认 1），胜者积分 +倍率、负者积分 -倍率；被 @ 的成员可接受或拒绝，@ 机器人自己时机器人按 1/倍率 的概率接受 |
| `/duel.accept @成员` | 接受对方发起的决斗邀请，如 `/duel.accept @张三`；对方未发起时机器人会提醒 |
| `/duel.reject @成员` | 拒绝对方发起的决斗邀请，如 `/duel.reject @张三` |
| `/duel.rank [high\|h [条数]] [low\|l [条数]]` | 查看本群决斗积分排行榜；默认同时显示高分榜与低分榜，也可以只查看其中一榜并指定条数（默认各显示前 10 名），如 `/duel.rank h 5` |
| `/duel.status` | 查看自己在本群进行中的决斗状态 |

## 实名群昵称检查（已禁用）

在开启检查的实名群里，机器人会自动检查每位成员发言时的群昵称。

昵称不符合格式或未设置群昵称时，机器人会发送一条提醒；提醒里的 `@你的群昵称` 只是文字，不会真正 @ 到你，按提醒中的建议修改群昵称即可。提醒有频率限制，短时间内不会重复打扰。

如果个别成员不参与检查，群主或管理员可以发送 `/exempt @成员 理由` 将其加入免验证名单，之后机器人不再检查该成员的群昵称。

## 猜拳决斗

在群里发送 `/duel @成员 [倍率]` 可向该成员发起一场猜拳决斗；倍率默认为 1、不能超过 100，胜者积分 +倍率、负者积分 -倍率。被 @ 的成员发送 `/duel.accept @发起人` 接受决斗，或发送 `/duel.reject @发起人` 拒绝。直接 @ 机器人自己发起决斗时，机器人会以 1/倍率 的概率接受（倍率越高越容易被拒绝）。

决斗开始后，双方各发送一次 QQ 的"包剪锤"（猜拳）表情，机器人根据双方手势判定胜负（平局双方积分不变），结果会即时播报。每个群的积分相互独立。

发送 `/duel.status` 可查看自己在本群的决斗状态：正在进行哪几场决斗、各自等待谁出手、距离超时还剩多久。

积分长期保存，发送 `/duel.rank` 可查看本群决斗积分排行榜：默认同时显示高分榜（按积分从高到低）与低分榜（按失分从多到少），也可以只查看其中一榜（如 `/duel.rank high`、`/duel.rank l`）并在其后指定条数（如 `/duel.rank high 5`），默认各显示前 10 名。

决斗长时间无人接受或接受后迟迟未出拳时，会自动超时结束（默认为 10 分钟）。

## 消息发送频率限制

为避免消息过于频繁触发平台限制，机器人对发送消息的频率做了限制（默认每分钟最多 9 条、每秒最多 1 条）。当频率达到上限时，机器人会暂时停止响应；仅在被 @、发送指令或私聊时回复"Bot忙，请稍后再试。"（引用机器人消息不算；每个群聊/私聊每分钟最多一次），稍等片刻后重试即可。

## 群昵称保护

机器人的群昵称（群名片）被他人修改时，机器人会自动把群昵称改回与自己的昵称一致。

机器人每次上线（包括掉线重连、重新登录）后，也会自动检查自己在所有群的群昵称，发现异常同样会恢复。

此外，机器人还会定期自动检查（默认每 2 分钟一次），确保群昵称最终与自己的昵称一致。
