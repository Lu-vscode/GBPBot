# GBPBot 用户手册

GBPBot（机器人昵称：Q群管家Pro）是一个 QQ 群机器人。发送指令即可与它交互：`/help`、`/react`、`/rf` 在群聊与私聊中均可用，决斗、签到与道具类指令仅在群聊中可用。

## 可用指令

指令以 `/` 开头，直接发送即可，无需 @ 机器人：

| 指令 | 说明 |
| --- | --- |
| `/help` | 把本手册的内容发给你 |
| `/react <表情>` | 给这条消息贴上指定表情，支持 QQ 自带表情与 emoji，如 `/react 😄`；若该消息引用了其它消息，则改为给被引用的消息贴表情 |
| `/rf [large\|l] [emoji\|e]`（别名 `/randomface`） | 随机发送一个表情：默认为 QQ 小黄脸，加 `large`（`l`）改为随机发送大黄脸（超级表情），加 `emoji`（`e`）改为随机发送 emoji，两个参数互斥 |
| `/duel @成员 [点数]` | 向指定群成员发起猜拳决斗；点数为不超过 100 的正整数（默认 1），胜者分数 +点数、负者分数 -点数；被 @ 的成员可接受或拒绝，@ 机器人自己时机器人会以一定概率接受 |
| `/duel.accept @成员` | 接受对方发起的决斗邀请，如 `/duel.accept @张三` |
| `/duel.reject @成员` | 拒绝对方发起的决斗邀请，如 `/duel.reject @张三` |
| `/duel.rank [high\|h [条数]] [low\|l [条数]]` | 查看本群决斗分数排行榜；默认同时显示高分榜与低分榜，也可以只查看其中一榜并指定条数（默认各显示前 10 名），如 `/duel.rank h 5` |
| `/duel.score` | 查看自己在本群的决斗分数 |
| `/duel.status` | 查看自己在本群进行中的决斗 |
| `/sign` | 在本群签到（每人每天一次），签到成功可获得决斗分数奖励与一件随机道具 |
| `/item.list` | 查看自己在本群拥有的道具（按品质由高到低） |
| `/item.detail <编号>`（别名 `/item.info`） | 查看自己拥有的某件道具的详细信息，如 `/item.detail 123` |
| `/item.craft <编号1> <编号2>` | 用两件同品质道具合成一件随机道具（金色传说与黑色诅咒除外），如 `/item.craft 123 124` |
| `/item.exchange @成员 <自己编号> <对方编号>` | 向指定群成员发起道具交换，如 `/item.exchange @张三 123 124` |
| `/item.exchange.accept @成员` | 接受对方发起的道具交换，如 `/item.exchange.accept @张三` |
| `/item.exchange.reject @成员` | 拒绝对方发起的道具交换，如 `/item.exchange.reject @张三` |
| `/item.use <编号> [参数]` | 使用自己拥有的一件道具，部分道具需要附加参数（如 @成员、道具编号），具体见该道具详情，如 `/item.use 123` |

## 猜拳决斗

在群里发送 `/duel @成员 [点数]` 可向该成员发起一场猜拳决斗；点数默认为 1、不能超过 100，胜者分数 +点数、负者分数 -点数。被 @ 的成员发送 `/duel.accept @发起人` 接受决斗，或发送 `/duel.reject @发起人` 拒绝。直接 @ 机器人自己发起决斗时，机器人会以一定概率接受。

决斗开始后，双方各发送一次 QQ 的"包剪锤"（猜拳）表情，机器人根据双方手势判定胜负（平局双方分数不变）。每个群的分数相互独立。

发送 `/duel.status` 可查看自己在本群进行中的决斗，发送 `/duel.score` 可查看自己在本群的决斗分数。

发送 `/duel.rank` 可查看本群决斗分数排行榜：默认同时显示高分榜（按分数从高到低）与低分榜（按失分从多到少），也可以只查看其中一榜（如 `/duel.rank high`、`/duel.rank l`）并在其后指定条数（如 `/duel.rank high 5`），默认各显示前 10 名。

决斗长时间无人接受或接受后迟迟未出拳时，会自动超时结束（默认为 10 分钟）。

决斗发起有限频：全部群聊合计每小时最多发起 20 次决斗，达到上限后的发起会被拒绝（限额按滑动 1 小时计算，最早的发起满 1 小时后自动恢复额度）。

## 签到

在群里发送 `/sign` 即可签到，每人每天一次（当天 0 点后重置）。

签到成功可获得决斗分数奖励（默认为 1 分，与猜拳决斗共用同一份分数）与一件随机道具；当天已经签过到时无法再次签到。

## 道具

签到成功后，除决斗分数外还会获得一件随机道具。道具的品质从低到高依次为：黑色诅咒、灰色垃圾、白色普通、绿色精良、蓝色稀有、紫色史诗、金色传说，品质越高的道具能力越强。其中**黑色诅咒**是特殊的负面道具：获得后不会留在背包中，而是立即自动使用并产生负面效果。

发送 `/item.list` 可查看自己拥有的道具（按品质由高到低），发送 `/item.detail <编号>`（别名 `/item.info`）可查看某件道具的详细信息（如 `/item.detail 123`）。

两件品质相同的道具（金色传说与黑色诅咒除外）可以合成一件随机道具：发送 `/item.craft <编号1> <编号2>`（如 `/item.craft 123 124`），结果大概率比材料品质高一级、小概率低一级、极小概率高两级；紫色史诗的大成功改为获得两件金色传说，灰色垃圾的合成失败得到的是黑色诅咒。

道具还可以与群成员交换：发送 `/item.exchange @成员 <自己编号> <对方编号>` 发起交换（如 `/item.exchange @张三 123 124`），交换为一换一、不要求品质相同，对方在 10 分钟内发送 `/item.exchange.accept @你` 接受或 `/item.exchange.reject @你` 拒绝，过期自动作废；不能与自己或机器人交换，耗损中的耐久道具不能用于交换。

发送 `/item.use <编号> [参数]` 使用自己拥有的一件道具（如 `/item.use 123`），效果依道具而定，部分道具需要附加参数（如 @成员、道具编号），具体见道具详情。道具按群独立保存。

## 消息发送频率限制

为避免触发平台限制，机器人限制了发送消息的频率：全部群聊与私聊合计默认每秒最多 1 条、每分钟最多 20 条、每小时最多 300 条；单个群聊或私聊默认每秒最多 1 条、每分钟最多 9 条、每小时最多 100 条。达到限额时机器人会暂时停止响应，稍等片刻后重试即可。

## 群昵称保护

机器人的群昵称被修改后会自动改回与昵称一致；每次上线（包括掉线重连、重新登录）以及定时检查（默认每 2 分钟一次）时也会自动恢复。
